To use https://cloudevents.io[CloudEvents], add the following dependency:

dependency:micronaut-gcp-function-cloudevents[groupId=io.micronaut.gcp]

In your application, create a class that extends api:gcp.function.cloudevents.GoogleCloudEventsFunction[]. Google publishes POJOs for https://github.com/googleapis/google-cloudevents-java[Google Cloud Events]. For example, to subscribe to a https://cloud.google.com/storage[Google Cloud Storage] event, your function may look like this:
snippet::example.cloudevents.Example[source="main", languages="java,kotlin,groovy"]

<1> The function extends from api:gcp.function.cloudevents.GoogleCloudEventsFunction[] with the type of the event data
<2> The `accept` method receives the CloudEvent context and the deserialized event data

[.lang-python]
NOTE: A Google Cloud Function needs a Java entry point class that the Functions Framework instantiates before any Micronaut application context (and with it the Python runtime) exists, so CloudEvents functions cannot be written in Python.
